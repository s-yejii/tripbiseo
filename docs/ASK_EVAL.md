# AI에게 묻기 결과 비교 (④ 신예지)

여행 중 "AI에게 묻기"(Text-to-SQL)를 고치기 전·후에 같은 질문을 물어 결과를 비교해요.

## 재는 방법
- 계정·위치: 시연 계정(qwer1234) + 가짜 GPS. 질문할 때 위치를 아래 표의 "위치" 칸에 적어요
- 영업 중인 곳만 보여 주므로 결과가 시각에 따라 달라요. 잰 날짜·시각을 같이 적어요
- 서버 로그 `backend/target/logs/tripbiseo.log`의 `AI에게 묻기 SQL: … → N곳` 줄로 SQL과 개수를 확인해요 (로그 파일 설정은 각자 `application-local.properties`)
  - 로그에는 질문 원문이 안 남아요. 질문을 아래 번호 순서대로 하나씩 물어요
  - `fallback`이 찍히면 AI로 못 찾고 반경 고르기로 넘어간 것
- 결과 수: SQL이 찾은 수 / 화면에 보인 수(닫힌 곳 뺀 뒤)

- 분위기 질문(1·2·6)은 리뷰 10개 글자 검색이라 0~1곳
