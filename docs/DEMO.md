# 시연 시나리오 (DEMO) — 갑자기 비어 버린 하루

최종 시연에서 보여 줄 흐름이에요. **여기 나오는 API가 진짜로 돌아가야 하는 것**이고, 나머지 화면은 가짜 데이터여도 시연은 돼요. 그래서 이 문서가 개발 우선순위의 기준이 돼요.

> 11/06 갱신: 시나리오 문서 "여행어때 시연 시나리오: 갑자기 비어 버린 하루"(11/03)로 바꿨어요. 아래 "팀이 정해야 할 것"이 정해지면 이 줄을 지워요.

> 시연 계정: 다른 PC에서는 `db/96_demo_account.sql`을 실행하면 `qwer1234`가 생겨요 (이미 있으면 그대로). 비밀번호는 팀 카톡으로만 공유해요. 시연 계정 기본값은 `DEMO_ACCOUNTS`(없으면 qwer1234).

## 시연 한 줄 요약

"서울 출장 2일차 미팅이 취소돼 비어 버린 28시간을 AI로 한 번에 채우고, 다음 날 카페에서 시간이 새서 KTX에 늦을 것 같아지자 앱이 먼저 알려 주고, 대안을 골라 적용하니 KTX에 늦지 않게 일정이 다시 맞춰진다."

## 이야기 순서

1. **1일차 14:50** 협력사가 내일 미팅을 다음 주로 미뤄요. 숙소·기차표는 회사가 결제했고 회식도 예약해서, 팀장님이 "내일은 서울 구경하고 가자, 총무가 일정 좀 짜 봐"라고 해요.
2. **1일차 15:00** 지하철에서 AI에게 말해요. "4명이에요. 오늘 18:30 문래 골목집 회식 예약돼 있고, 내일 19:00 서울역 KTX예요. 숙소는 영등포예요. 팀장님 사모님 선물도 사야 해요."
3. **1일차 15:05** AI가 물어볼 것만 더 묻고 이틀 일정을 한 번에 내놓아요. "오늘 저녁이 오리요리라 내일 점심은 겹치지 않게 중식으로 골랐어요" 같은 이유도 같이 떠요.
   - 1일차: 호텔GMS 체크인 16:00 → 문래 골목집 18:30 (시간 고정) → 하나마토 문래
   - 2일차: 무탄 여의도점 11:00 → 더현대 서울 → 테디뵈르하우스 → 여의도 한강공원 → 영등포 타임스퀘어 (선물, 꼭) → 서울역 18:30 도착 (시간 고정)
4. **1일차 15:10** 일정을 확인하고 단톡방에 공유해요.
5. **2일차 오전~15:30** 무탄 점심 → 더현대 서울 → 지하 1층 테디뵈르하우스. 원래 15:30에 일어날 계획이에요.
6. **2일차 15:54** 빵이 20분 늦게 나오고 팀장님은 "천천히 먹고 가자~"라고 해요. 폰이 울려요. **"KTX 19:00에 맞추려면 14분 늦어요."** 카페에 계획보다 24분 더 있었고, 이대로면 서울역에 18:44에 도착해요.
7. **2일차 15:55** 알림을 누르면 대안 3개가 나와요.

   | 대안 | 바뀌는 것 | 서울역 여유 |
   |---|---|---|
   | A 시간 줄이기 (추천) | 여의도 한강공원 60분 → 30분 | 16분 |
   | B 한 곳 빼기 | 한강공원 빼기 | 56분 |
   | C 장소 바꾸기 | 가까운 다른 곳으로 | 23분 |

   타임스퀘어는 "꼭"이라 줄이거나 빼는 대상에서 빠져 있어요.
8. **2일차 15:56** A를 적용하면 "서울역 18:14 도착 · 여유 16분"이 떠요. 바뀐 일정이 팀원 폰과 단톡방에도 가요.
9. **2일차 이후** 15:54 출발 → 도보 10분 → 16:04 한강공원 30분 → 지하철 20분 → 16:54 타임스퀘어 50분 → 택시 30분 → 18:14 서울역.
10. **2일차 19:00 이후** KTX가 출발하고 회고가 떠요. "카페에서 계획보다 24분 더 머물렀어요."

## 흐름

시연은 두 덩어리예요. **시연Ⅰ**은 1일차 AI 일정 짜기, **시연Ⅱ**는 2일차 늦음 알림부터 회고까지예요.

| # | 장면 | 화면 | 진짜로 돌아가야 하는 API | 담당 |
|---|---|---|---|---|
| 1 | 로그인 (첫 화면에서 짧게) | member/LoginView | `POST /api/auth/login` | ① |
| 2 | Ⅰ 1일차 15:00 AI 대화로 조건 입력 (인원, 회식 18:30, KTX 19:00, 숙소, 선물) | plan/PlanAiView, plan/PlanChatView | `POST /api/plans/chat` | ③ |
| 3 | Ⅰ 1일차 15:05 이틀 일정 한 번에 만들기, 추천 이유 보여 주기 | plan/GeneratingView | `POST /api/plans/generate/stream` | ③ |
| 4 | Ⅰ 1일차 15:10 일정 확인·수정, 메모, 단톡방 공유 | trip/PlanCheckView | `POST /api/plans/check`, `POST /api/trips` | ② |
| 5 | Ⅱ 2일차 여행 시작, 장소에 들어가면 자동 도착 기록 | live/LiveView | `POST /api/trips/{id}/start`, `POST /api/trips/{id}/live/track` | ②, ④ |
| 6 | Ⅱ 2일차 15:54 위치와 머문 시간으로 늦음 감지 → "KTX에 14분 늦어요" 알림 | live/LiveView → live/LiveDelayView | `POST /api/trips/{id}/live/status` | ④ |
| 7 | Ⅱ 2일차 15:55 대안 A·B·C 보기 | live/AlternativesView | `POST /api/trips/{id}/live/alternatives` | ④ |

| 9 | Ⅱ 2일차 19:00 이후 계획 대비 실제 비교 회고 | after/RetroView | `GET /api/trips/{id}/retro` | ⑤ |
